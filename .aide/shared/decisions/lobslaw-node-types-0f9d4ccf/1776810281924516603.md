# lobslaw-node-types

**Decision:** MemoryNode (vector+session), StorageNode (object+FUSE), PolicyNode (RBAC+rules), ComputeNode (agent core+tools), GatewayNode (HTTP/WS+channels+auth)

## Rationale

Separation of concerns allows independent scaling and fault isolation per node type
