# lobslaw-memory-introspection

**Decision:** Four new LLM-accessible builtins expose memory machinery to the bot: memory_forget {query|ids|before} cascades through dream consolidation (RiskDestructive, confirmation required); memory_correct {id, new_content} supersedes a memory with a new version, old marked superseded + audit-logged, no confirmation (it's improving not destroying); memory_recent {retention, since, limit} lists recent writes to session/episodic/long-term tiers — default last 20 long-term; dream_recap {since, limit} shows recent dream/REM consolidation outputs (source counts, summary text, timestamps). All tools return structured JSON — the agent narrates in SOUL voice (humanisation rule lives in Personality & Style section of the system prompt). Deliberate omission: no 'show forgotten' surface — 'remembering what you forgot' is a contradiction the bot shouldn't be able to express. Audit log retains forgotten records for operator inspection.

## Rationale

Infrastructure for forget/correct/dream is already shipped (lobslaw-retention-forget + lobslaw-forget-cascade decisions), but no LLM surface existed — bot could promise to forget but not actually forget. User can now say 'forget that' or 'actually, correct that to X' and get follow-through. Dream_recap + memory_recent answer the 'what have you learned about me recently' and 'what did you dream about' questions that a personal assistant gets asked. JSON output + SOUL-narrated delivery keeps the responses in-voice rather than robotic tool-output parroting.
