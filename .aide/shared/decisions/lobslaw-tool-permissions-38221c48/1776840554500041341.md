# lobslaw-tool-permissions

**Decision:** Tools not assumed to exist. Policy gates all tool access. Dangerous filter blocks rm -Rf/*, dd with device targets, injection patterns always. Path enforcement restricts to sandboxed/allowed paths. Sidecar model for elevated-access tools via narrow gRPC API

## Rationale

Zero-trust tool model. Git doesn't exist unless policy allows it. Dangerous filter is a pre-policy safety net, not a replacement for RBAC
