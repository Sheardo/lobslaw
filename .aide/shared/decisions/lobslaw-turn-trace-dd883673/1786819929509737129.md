# lobslaw-turn-trace

**Decision:** Per-turn timing, token and cost telemetry is EXPORTED, not stored in raft and not reported inside the assistant. A turn emits a tree of spans (llm_call, tool_call, embedding, retrieval, compaction, ingest) with parent links, timings, usage and cost, to any combination of OpenTelemetry, a newline-delimited JSON file, and a webhook. Off by default. Spans carry sizes, counts, timings and names — never message text, tool arguments or tool output. Emission is asynchronous, bounded, and never on the reply path; a dropped span is counted, not retried. Tool cost attribution measures the tokens a tool result contributed to every SUBSEQUENT prompt in the turn, not the single call that produced it.
