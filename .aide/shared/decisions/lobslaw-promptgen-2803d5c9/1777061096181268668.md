# lobslaw-promptgen

**Decision:** Sections in the assembled system prompt carry explicit priority banners (CRITICAL/PRIMARY/CONTEXT/BACKGROUND) rendered as **[LABEL]** beneath the heading. Priority levels: CRITICAL (Identity, Safety, Operating Principles) — non-negotiable; PRIMARY (Personality & Style, Available Tools, Installed Skills) — instructions; CONTEXT (Current Time, Runtime, Workspace, Environment) — ambient state; BACKGROUND (Recent Context from this session, Recalled Memory from past sessions) — reference only. SOUL is split: Identity section holds hard identity (scope/culture/language/min_trust_tier/persona_description) at CRITICAL; Personality & Style section holds emotive dials (formality/directness/humor/etc) at PRIMARY. ContextBlock gains a Category field (short-term | long-term) driving a 2-section split render (Recent Context + Recalled Memory). Tooling moved UP in section order (right after Safety) — previously the model confabulated a shorter tool list because the full list was buried too deep in the prompt.

## Rationale

Reasoning-model attention is not uniform across long prompts. Three real bugs pushed this redesign: (1) bot confabulated 'I don't have a web fetch tool' when fetch_url was present but buried after 6 other sections; (2) memory recall blended with current-turn context, making model unable to distinguish 'user just said X' from 'user said X three months ago'; (3) SOUL identity scores were rendered at the same priority as operating principles — humor:3/10 shouldn't be non-negotiable the way 'never elevate trust tier' is. Explicit priority banners give the model a fast-scan hierarchy it can apply under attention pressure. Tool descriptions already clarify local-vs-web scope; promptgen reordering + summary headers make those descriptions actually get read.
