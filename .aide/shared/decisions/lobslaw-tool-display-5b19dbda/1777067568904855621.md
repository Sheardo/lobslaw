# lobslaw-tool-display

**Decision:** Telegram channel renders tool calls opencode-style: 'Read(/etc/hosts)', 'Grep(lobslaw)', 'Gmail.Search(urgent)' — TitleCase with namespace dots preserved, primary argument inside parens. Primary-arg priority order: pattern > query > url > path > id > name (semantic 'what' wins over location). The breadcrumb (italic 'ran X, Y, Z' line) prefixes the final reply when SOUL EmotiveStyle.Directness < 7 (chatty); direct deployments skip it. Policy denials surface as a separate 🚫 message before the reply, regardless of SOUL — transparency on enforcement is operator-grade and shouldn't be gated by personality.

## Rationale

Channel-level rendering doesn't change tool internal names — MCP tools stay namespaced 'gmail.search' for collision-resistance, but display sees 'Gmail.Search'. Breadcrumb is a chatty-only feature because direct-SOUL bots want clean replies; policy denials are universal because the alternative (LLM may or may not narrate) leaves users guessing why the bot didn't do what they asked.
