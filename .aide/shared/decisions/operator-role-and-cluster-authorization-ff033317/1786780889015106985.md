# operator-role-and-cluster-authorization

**Decision:** An operator is a role over the deployment, not a principal with universal read. The cluster gRPC authenticates callers by mTLS peer certificate and derives the audience from the caller's class — peer nodes may assert a principal, operators get the unrestricted audience, everything else is denied. Only an operator may mark a record SHARED.
