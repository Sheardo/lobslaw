# lobslaw-provider-modality

**Decision:** Providers are separated into DRIVERS (compiled-in wire protocols: openai, anthropic, gemini, mock, external) and PROVIDERS (configured instances: label + modality + driver + endpoint + model + credential + backup). One [[provider]] table replaces [[compute.providers]] plus the separate vision/audio/pdf/embedding config blocks. Modalities are chat, embedding, vision, transcribe, document, speak, image, video. chat and embedding are infrastructure called directly; every other modality is surfaced to the model as a TOOL. Failover chains are per-modality, generalising the existing chat Backup pointer.
