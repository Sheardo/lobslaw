# lobslaw-embeddings

**Decision:** Embeddings are computed IN-PROCESS by default: a pure-Go BERT/XLM-RoBERTa encoder in internal/embedder, no CGO, no API key, no endpoint, no egress. type = "builtin" in [compute.embeddings] with a model name; remote providers remain supported via type = "remote" for anyone who wants one. Weights load from safetensors ONLY — pickle is refused, because unpickling is arbitrary code execution and a model file is untrusted input. Weights are mmap'd, so a 91 MB model is not also 91 MB of Go heap, and the Model owns the mapping for its lifetime. The vector kernel has two implementations selected at build time: an archsimd path behind goexperiment.simd on amd64, and a portable path that is tested and benchmarked as a first-class citizen rather than an untested fallback. Two tokenizers are supported, WordPiece and SentencePiece Unigram (Viterbi over a Darts double-array precompiled_charsmap). Models are vendored as GitHub release assets with SHA256 verified on download. Default is all-MiniLM-L6-v2. VECTORS CARRY THE IDENTITY OF THE MODEL THAT MADE THEM: every vector record is stamped with its embedding model, a node whose configured model disagrees with its stored vectors REFUSES TO BOOT, the repair is lobslaw memory reembed which proposes every write through raft, and --allow-embedding-model-change is the one-shot escape hatch that exists because the guard refuses at boot while the repair needs a running node. Search skips vectors whose width does not match the query and falls back to lexical; no embedding-dependent path is ever simply switched off.

## Rationale

This discharges a tension the existing decisions already named. lobslaw-retrieval-raft-only rejected external vector stores partly because 'shipping embeddings to a network service is an egress and data-classification event in a product whose distinguishing feature is architecturally-controlled egress' — but every available embedder then needed an API key, so that event happened on every memory written. A built-in encoder removes it: the memory of a personal assistant never leaves the machine to be indexed. Model choice was measured, not taken from model cards, using lobslaw embed-eval against the rig's own corpus: all-MiniLM-L6-v2 at 91 MB scored recall@1 80%, recall@3 95%, margin +0.165, 61 ms/doc; multilingual-e5-small at 471 MB scored 75/95/+0.025/107 ms; bge-m3 at 2.3 GB scored 80/95/+0.073/809 ms. MiniLM matches bge-m3's recall with a wider margin at a 25th of the size and a 13th of the time, so multilingual buys retrieval across languages and only that. Model identity is stamped because vectors from two models are not comparable and the failure is silent: search returns confidently wrong neighbours rather than an error, which is worse than returning none. safetensors-only is not a preference; refusing pickle is the difference between loading data and executing whatever the file's author chose.
