# lobslaw-external-drivers

**Decision:** An operator-written provider driver is a SKILL that declares provides.modality in its manifest, not a new plugin mechanism. It is registered as a provider for that modality rather than as a bare tool, and invoked with the modality's JSON request shape on stdin/stdout — so any language works. External drivers are offered for tool modalities (vision, transcribe, document, speak, image, video) but NOT for chat or embedding.
